# 1.1.0

Planned release; no tag or publication yet.

- Add `suspend KeyValue.setAndAwait(value)` for caller-owned write completion and error propagation.
- Memory updates shared state; DataStore awaits `edit`. Mapping, default and required adapters forward
  acknowledged writes. Conversion/backend failures and cancellation propagate.
- Required acknowledged writes reject runtime null before forwarding, including explicitly nullable
  type arguments, preserving the stored value.
- Preserve existing `set`, including DataStore asynchronous replacement and error logging.
- Existing custom backends remain compatible and reject acknowledged writes until they override the method.
- Clarify observed Flow values, cache fallback, completion and cancellation limits. No new read API is needed:
  `get().first()` observes without the `current()` timeout/fallback.
- Add shared contract tests and verify acknowledged persistence through DataStore file recreation on JVM.

Targets are unchanged. DataStore is operational on Android, JVM and Apple; JS/Wasm constructors remain unsupported.
