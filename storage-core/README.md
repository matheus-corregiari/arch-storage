# storage-core

Backend-independent typed entries, Flow, defaults, mapping, JSON and Compose state.

Artifact: `io.github.matheus-corregiari:storage-core`. This extraction is not independently released yet.
For local use, publish `0.0.0-SNAPSHOT` with `./gradlew ciPublishLocal`.

See [getting started](../docs/getting-started.md), [concepts](../docs/core-concepts.md),
[recipes](../docs/recipes.md) and [platform support](../docs/index.md#platform-support).

Tests run through `./gradlew :storage-core:jvmTest` or the project-wide `ciCoverage` gate.
API docs are generated by `./gradlew ciDocs` into `docs/api/storage-core`.
